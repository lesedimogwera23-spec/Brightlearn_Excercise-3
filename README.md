SQL CASE Statements Exercise

About This Project

This project is part of my journey into data analytics. I completed SQL exercises to practise using CASE statements to classify data into different categories.

As a beginner data analyst, I am learning how SQL can be used to organise data and make it easier to understand.

What I Learned

How to use CASE, WHEN, THEN, ELSE, and END.

How to classify data into different categories.

How to use conditions such as =, >, <, >=, and <=.

How to combine conditions using AND.

How to create new column names using AS.

How to calculate percentages and use them to classify results.

Exercises Completed

The exercises covered different examples, including:

Classifying products by price.

Categorising orders by value.

Classifying employees by department and salary.

Assigning letter grades to students.

Categorising delivery performance.

Labelling support ticket priorities.

Calculating student attendance percentages.

Classifying product stock levels.

Categorising classes by student numbers.

Identifying payments eligible for discounts.

Tools Used

SQL

MySQL (for practising SQL concepts)

What I Learned From This Project

This exercise helped me understand how SQL can be used to apply conditions to data and create meaningful categories. I also practised predicting query results and checking whether the output columns matched the requirements.
